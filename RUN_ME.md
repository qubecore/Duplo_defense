# RUN ME
1. Launch Hytale.
2. Open the save `Bank Defense`.
3. Wait for the hotbar tools to appear.
4. Slots `1-4`: build or upgrade towers by clicking build slots.
5. Slot `5`: start the next wave by click.
6. Slot `6`: sell a tower by clicking it. Refund is `75%` of invested cost.
7. Slot `9`: open the control menu.
8. Control menu buttons: add money, remove money, or reset the match.
9. Optional fallback command for selling: `/bankdefense sell`
