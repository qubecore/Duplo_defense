# Public Release Scope

This file defines what should go into the public CurseForge release package.

## Include
- Built mod jar from `dist/`
- The final world/save package prepared for the mode
- Public installation instructions
- Public description, credits, and release notes

## Exclude
- `build/`
- `generated/`
- `install_backups/`
- `tmp_reflect/`
- `tools/`
- `SETUP_LOG.md`
- `PROJECT_STATE_COMPACT.md`
- `STABILIZATION_PLAN.md`
- `LOCALIZATION_FULL_LIST.txt`
- `localization_audit_report.txt`
- `RUN_ME.md`
- `DumpApi.java`
- `tmp_dump.java`
- `tmp_editor_empty_cube_texture.png`
