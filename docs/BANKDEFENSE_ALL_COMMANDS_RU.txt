Полный список команд BankDefense

Префикс:
/bankdefense

Обозначения:
- <...> = обязательный аргумент
- [...] = необязательный аргумент
- если аргумент не указан, берётся значение по умолчанию

================================================================
1. Диагностика и общий статус
================================================================

/bankdefense status
Показывает общий статус мира: конфиги, маркеры, маршруты, слоты, матч, прогрессию, визуализацию и результаты валидации.

/bankdefense duostatus
Показывает статус только Duo-режима: duo NPC, duo старты, duo спавны, duo маршруты, duo chest points, duo слоты и duo validation.

/bankdefense validate
Проверяет файлы и данные карты на ошибки.

================================================================
2. Матч, режимы, волны, тестовый режим
================================================================

/bankdefense match solo
Переключает мир в Solo-режим.

/bankdefense match duo
Переключает мир в Duo-режим.

/bankdefense match start
Начинает игру или запускает следующую волну.

/bankdefense match reset
Сбрасывает текущий матч.

/bankdefense start
Быстрый алиас для /bankdefense match start.

/bankdefense reset
Быстрый алиас для /bankdefense match reset.

/bankdefense duotest on
Включает Duo solo-test режим: можно тестировать Duo одному.

/bankdefense duotest off
Выключает Duo solo-test режим и возвращает обычные правила Duo.

/bankdefense duotest status
Показывает, включён ли Duo solo-test режим.

/bankdefense duofillmax
Для тестов заполняет все Duo-пады самыми дорогими башнями максимального уровня.

/bankdefense reward
Открывает текущее окно выбора модульной награды, если награда сейчас активна.

/bankdefense rewardmenu
Принудительно подготавливает и открывает меню модульной награды.

/bankdefense ranges
Переключает показ радиусов башен.

================================================================
3. HUD, меню и UI
================================================================

/bankdefense hud on
Показывает кастомный HUD BankDefense для текущего игрока.

/bankdefense hud off
Скрывает кастомный HUD BankDefense для текущего игрока.

/bankdefense hud toggle
Переключает состояние кастомного HUD BankDefense.

/bankdefense hud status
Показывает, включён ли кастомный HUD BankDefense у текущего игрока.

/bankdefense menu
Открывает чит-меню/служебное меню BankDefense.

/bankdefense progression
Открывает дерево прогрессии.

4. Прогрессия, статистика, обучение
================================================================

/bankdefense progressreset

14. Слоты: базовые команды
================================================================

/bankdefense slot add [type]
Добавляет слот в текущую точку.
По умолчанию type = standard.

/bankdefense slot remove [radius]
Удаляет ближайший слот.
По умолчанию radius = 3.

/bankdefense slot clear [type]
Очищает слоты указанного типа.
По умолчанию type = all.

/bankdefense slot list
Показывает все слоты.

Допустимые type:
- standard
- super
- trap
- tutorial
- tutorial_super
- tutorial_trap
- all
