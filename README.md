# Duplo TD

Author: QubeCore

Duplo TD is a custom solo tower defense mode for Hytale.

This repository contains the source project used to build the playable mod, its data, UI, and supporting assets.

Current project focus:
- Solo mode
- Duo mode
- Full in-game tutorial
- Tower, trap, boss, and progression systems
- Russian and English localization

Project identity:
- Project name: Duplo TD
- Internal mod id: `BankDefense`
- Author: QubeCore

Repository notes:
- `src/` contains the actual mod sources and resources
- `scripts/` contains local build/install helpers
- `dist/` contains built jars

This repository is an authoring workspace, not the final public mod package.
